# Phase 17 — UX QA, Scale & Hardening

## Objective
Validate the entire UX at realistic operational volume.

## Test Volumes
- 50 participants.
- 500 participants.
- 5,000 participants.
- 20,000+ participant records where applicable.

## Validate
- table performance perception;
- pagination/virtualization behavior;
- filter speed;
- long event names;
- large MABAR groups;
- blast recipient lists;
- failed delivery states;
- mobile layouts;
- keyboard navigation;
- empty/error/loading states.

## Acceptance Criteria
- High-volume pages remain usable.
- Bulk actions remain safe.
- No visual regression from scale.
