# Phase 12 — Conversion UX

## Objective
Visualize and operate the webinar-to-bootcamp conversion funnel.

## Implement
- Voucher status.
- Lead/conversion list.
- Follow-up actions.
- Funnel summary.
- Participant conversion timeline.

## Acceptance Criteria
- Admin can see where prospects are stuck.
- Voucher state is distinguishable from conversion state.
- Conversion actions remain contextual to the participant/event.
