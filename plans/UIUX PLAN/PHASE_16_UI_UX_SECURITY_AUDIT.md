# Phase 16 — Security & Audit UX

## Objective
Expose secure, understandable auditing for sensitive operations.

## Implement
- Audit log search/filter.
- Actor, action, entity, timestamp.
- Before/after detail for material changes.
- Sensitive-action confirmation language.
- Security/system status surface.

## Acceptance Criteria
- Audit records are readable by non-technical operators.
- Sensitive actions have explicit confirmation.
- Audit UI never exposes secrets.
