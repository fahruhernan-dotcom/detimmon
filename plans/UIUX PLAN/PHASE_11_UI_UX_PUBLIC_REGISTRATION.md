# Phase 11 — Public Registration Web UX

## Objective
Create the primary public registration experience for future events.

## Primary Flow
Landing → Event Details → Package → Participant Data → Review → Submit → Payment Instructions → Proof Upload → Confirmation

## Implement
- Event landing template.
- Registration wizard.
- Package selection.
- MABAR member entry.
- Review page.
- Payment instruction state.
- Upload proof state.
- Confirmation/reference page.

## Principles
- Minimize cognitive load.
- One decision per step.
- Show price impact immediately.
- Preserve entered data.
- Strong mobile-first design.

## Acceptance Criteria
- New event can reuse the same registration UI.
- Form content derives from event configuration.
- No event-specific hardcoded layout is required.
