# Phase 14 — Participant 360 UX

## Objective
Create one calm, complete participant profile across events.

## Implement
- Identity header.
- Event history.
- Registration history.
- Payment history.
- Tickets.
- Attendance.
- Certificates.
- Vouchers/conversions.
- Communication history.
- Activity timeline.

## Acceptance Criteria
- A user can understand a participant journey without jumping between modules.
- Event context is explicit on every historical item.
