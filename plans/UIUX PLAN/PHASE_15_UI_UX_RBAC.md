# Phase 15 — RBAC UX

## Objective
Make permissions understandable without exposing inaccessible controls unnecessarily.

## Implement
- Role-aware navigation.
- Role display in profile.
- Permission-aware actions.
- User management.
- Role assignment UI.

## Acceptance Criteria
- Users do not see actions they cannot perform where practical.
- Restricted actions explain why they are unavailable when needed.
- Owner/admin/finance/CS/event-manager/viewer workflows remain consistent.
