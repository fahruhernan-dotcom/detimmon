# Phase 8 — Drive UX

## Objective
Make Drive a transparent file archive while keeping Supabase as application source of truth.

## Implement
- File metadata panel.
- Proof preview entry.
- Certificate archive link.
- File type/size/modified metadata where useful.
- Missing/inaccessible file state.

## Acceptance Criteria
- File identity is based on Drive file ID.
- Users understand whether a file exists, is inaccessible, or is loading.
- No duplicated storage UI is introduced.
