# Phase 10 — WhatsApp UX

## Objective
Add WhatsApp as an external message channel without coupling the UI to one provider.

## Implement
- Channel selector.
- Provider status.
- Message preview.
- Delivery state consistent with email.
- Context-aware quick actions from participant detail.

## Acceptance Criteria
- WhatsApp and email use consistent communication concepts.
- Provider implementation details do not leak into normal operator workflows.
