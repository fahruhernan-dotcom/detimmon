# Phase 7 — Google Workspace Integration UX

## Objective
Expose Google Form/Sheets/Drive integration without making Google the mental model of the application.

## Implement
- Integration status screen.
- Event-specific source configuration.
- Sync status and last sync time.
- Manual sync control with progress.
- Sync error details.
- External record reference display.

## Acceptance Criteria
- Google sources are shown per event.
- Sync failures are actionable.
- Admin never needs to edit source IDs in code.
