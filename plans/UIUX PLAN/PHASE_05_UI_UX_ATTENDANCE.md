# Phase 5 — Attendance UX

## Objective
Turn attendance into a quick operational monitor.

## Implement
- Attendance overview.
- Live/near-live status summary.
- Participant attendance list.
- Join/leave/duration detail.
- Manual check/override with audit reason.

## Acceptance Criteria
- Admin can distinguish registered, joined, attended, no-show.
- Attendance status is readable without relying only on color.
- Manual changes are clearly marked as manual.
